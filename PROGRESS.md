# Progress

What's done, what's broken, what's next. Newest entry first. Each session adds a row before it
ends.

## Where things stand

- **Done:** the skeleton (Session 1), the quality system (Session 2), the forge (Session 3),
  the advancement trail, Jade overlay and icon (Session 4) and the JEI and REI Tempering tab
  (Session 5), and the hearth knows other mods' metals by name (Session 5b). 151 game-test
  checks; `-PtestJade`, `-PtestJei`, `-PtestRei` compatibility runs.
- **Broken:** nothing known in Forgemark. REI itself logs an error per vanilla recipe on a
  NeoForge dedicated server on 26.3 (the same without Forgemark installed). The textures and
  icon come from `tools/gen-textures.js`; a file in `art/` with the same name replaces one.
- **Next:** the parts that need Gabby at the keyboard: sounds and particles tuned by feel in a
  real game, a play test of the strike bar's speed and zones (2 s sweep, wide zone 0.12, narrow
  0.04, lag window 0.15), and a two-player dedicated server run by hand on each loader. The
  Beyond the Dragon and Mythic Metals runs wait until those mods reach 26.3 (Beyond the
  Dragon's main is on 26.1.2). EMI and WTHIT still have no 26.3 build. Ideas to weigh: oil
  quenching, bows and shields, the trip-hammer.
